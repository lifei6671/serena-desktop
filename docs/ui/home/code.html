如何初始化并同步项目

在已有 Git 仓库的根目录打开 PowerShell，执行以下命令，为当前仓库创建 Serena 项目配置并建立索引。完成后点击“同步项目”。

serena project create --index
找不到 serena 命令时

仍要在仓库根目录执行以下命令，使用 Desktop 检测到的 Serena 和同步配置目录。

$env:SERENA_HOME = 'C:\Users\lifei\.serena'
& 'C:\Users\lifei\AppData\Roaming\io.github.lifei6671.serena-desktop\runtime\bin\serena.exe' project create --index

如果仓库已有 .serena/project.yml，请改用以下命令：

serena project index

大项目可在终端查看进度；等待命令执行完成后再同步。
